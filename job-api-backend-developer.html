API / Backend Developer

Help build reliable, secure and scalable backend services that power the Game API platform.

Remote / Nigeria Full-time / Contract Engineering

About the role

You will work on backend systems, APIs, integrations and services that make Game API dependable for developers and partners. We are looking for someone who enjoys solving practical engineering problems and building clean, maintainable systems.

What you will do

  • Design, build and maintain REST APIs and backend services.
  • Work with databases, authentication, validation and integrations.
  • Improve reliability, performance, security and monitoring.
  • Collaborate with frontend developers and product stakeholders.
  • Write clear technical documentation and maintain quality code.

Requirements

  • Practical backend development experience.
  • Strong understanding of HTTP, REST APIs and JSON.
  • Experience with at least one backend language such as JavaScript/Node.js, Python, PHP, Java or similar.
  • Understanding of SQL or NoSQL databases.
  • Ability to use Git and work independently.

What we value

We value problem-solving, honesty, continuous learning, good communication and the ability to turn ideas into dependable products. Strong portfolios and practical projects are welcome even when a candidate does not have a traditional career path.

Please submit truthful information. Your application and documents may be reviewed as part of the selection process.
