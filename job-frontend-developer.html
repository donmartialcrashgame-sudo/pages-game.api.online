Frontend Developer

Create polished, responsive and accessible web experiences for Game API developers, partners and visitors.

Remote / Nigeria Full-time / Contract Product & Engineering

About the role

You will help shape the visual experience of Game API by creating fast, responsive and user-friendly interfaces. You will work closely with backend and product teams to turn ideas into production-ready experiences.

Responsibilities

  • Build responsive pages and reusable interface components.
  • Translate designs and product requirements into working interfaces.
  • Connect frontend experiences to APIs and backend services.
  • Improve accessibility, performance and mobile usability.
  • Test, debug and maintain frontend code.

Requirements

  • Strong HTML, CSS and JavaScript fundamentals.
  • Experience with responsive web development.
  • Knowledge of a modern frontend framework is an advantage.
  • Comfortable using Git and browser developer tools.
  • A portfolio or practical projects demonstrating your skills.

What we value

Good visual judgment, clean code, attention to detail, curiosity and the ability to build interfaces that real people can use comfortably.

Applications are reviewed based on skills, experience, portfolio quality and fit for the role.
